pythainlp.lm.phayathaibert

Note

pythainlp.phayathaibert has moved to pythainlp.lm.phayathaibert. Importing from pythainlp.phayathaibert still works but emits a DeprecationWarning and will be removed in 6.0.

The pythainlp.lm.phayathaibert module is built upon the phayathaibert base model.
